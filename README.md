# Εκπαιδευτικό Escape Room στο Unity
**Εκπαίδευση σε Αλγορίθμους και Δομές Δεδομένων μέσω εφαρμογής Εικονικής Πραγματικότητας**
**Education in Algorithms and Data Structures through a Virtual Reality Application** 

Διπλωματική Εργασία, Πανεπιστήμιο Δυτικής Αττικής, Τμήμα Ηλεκτρολόγων και Ηλεκτρονικών Μηχανικών
Φοιτητής: Εμμανουήλ - Άγγελος Κοϊνάκης, Α.Μ.: 19387107
Επιβλέπουσα Καθηγήτρια: Μαρία Ραγκούση
Έτος: 2026

**Abstract** This repository contains the code of a diploma thesis that presents the design and implementation of a 3D educational escape room game in Unity. The game consists of five rooms, each covering a different topic of the C programming language and data structures.

Συγκεκριμένα ο σκοπός της εργασίας, ήταν η υλοποίηση μιας εφαρμογής με τη γλώσσα προγραμματισμού C ως το βασικό γνωστικό αντικείμενό της και με λογική λειτουργίας, αυτήν της λογικής διαφυγής χώρου (escape room). Μέσω αυτής, οι γνώσεις του χρήστη δοκιμάζονται πάνω σε συγκεκριμένες θεματικές ενότητες βασικών όρων της γλώσσας προγραμματισμού C και δομών δεδομένων.

| Δωμάτιο | Θεματική ενότητα | Φάκελος |
| 1 | Δηλώσεις μεταβλητών και τύποι δεδομένων στη C | `room1` |
| 2 | Αριθμητικοί δείκτες στη C | `room2` |
| 3 | Δείκτες (pointers) στη C | `room3` |
| 4 | Στοίβα (Stack) | `room4` |
| 5 | Συνδεδεμένη Λίστα ( Linked List) | `room5` |

Ο φάκελος `general` περιέχει τους κώδικες που αφορούν όλους τους χώρους του παιχνιδιού (κίνηση παίκτης, πόρτες, χρονόμετρο, πόντοι, πίνακας κατάταξής)

## Σημειώσεις

- Ο φάκελος `room4/extra scripts` περιέχει τους κώδικες που ανήκουν σε παλαιότερη έκδοση του 4ου δωματίου και δεν συμμετέχουν στην τελική μορφή του παιχνιδιού και περιλαμβάνονται διότι αναφέρονται σε άλλους ενεργούς κώδικες.
- Το ίδιο ισχύει και για τον κώδικα `AutoOpenDoor` στον φάκελο `general` ο οποίος αναφέρεται από τον `DoorController`
-  Οι κώδικες `AutoSitzViewRoom4` και `DragObject3DRoom4` βρίσκονται στον φάκελο `room5` διότι στην τελική μορφή του παιχνιδιού αυτοί αξιοποιούνται στο 5ο δωμάτιο.
